# LiveBoard - דף עבודה לתלמידים

## מטרת התרגיל

בתרגיל זה תבנו לוח הודעות כיתתי בזמן אמת. כל הודעה נשמרת ב-Cloud Firestore, וכל מכשיר שמחובר לאותה אפליקציה יקבל את העדכון בלי לרענן את המסך.

פתחו את התיקייה `LiveBoard-Student` כפרויקט נפרד ב-Android Studio. כתבו ב-Java בלבד. שתי המשימות הנדרשות מפורטות להלן; אין צורך לשנות את ה-XML, את ה-`ListView` או את הקוד שמעדכן אותו בזמן אמת.

## הכנה ב-Firebase

קובץ `app/google-services.json` כבר נמצא בפרויקט ומקושר לפרויקט Firebase של הכיתה. לפני ההרצה, במידת הצורך, המורה צריך לפתוח את Firebase Console:

1. בחרו **Firestore Database** וצרו מסד נתונים.
2. לשיעור הראשוני אפשר לבחור **Test mode**.
3. לאחר תקופת ההתנסות אל תשאירו את המסד פתוח: Test mode מאפשר גישה רחבה ומיועד להדגמה בלבד. הגדירו Security Rules מתאימים, או השתמשו באימות משתמשים לפני שימוש אמיתי.

האוסף המשותף נקרא בדיוק `board`. כל תלמיד וכל אמולטור משתמשים באותו אוסף, ולכן כל הודעה שתישלח תופיע לכולם.

## משימות חובה

אין כאן פתרונות קוד למשימות:

1. צרו בעצמכם את `Message.java` בחבילה `com.shamir.liveboard`. למחלקה יש **בדיוק שני מאפיינים**: `sender` ו-`content`. הוסיפו בנאי ציבורי ללא ארגומנטים (Firestore זקוק לו), בנאי שמקבל שולח ותוכן, getters, setters ו-`toString()`.
2. ב-`MainActivity.java`, השלימו רק את שני ה-`TODO`-ים בתוך אירוע הלחיצה על כפתור השליחה: צרו `Message` מהערכים שנקראו, ושמרו אותו באוסף המשותף `board`. בדיקת השדות הריקים כבר קיימת ואין לשנותה.

## קוד שכבר מסופק

החיבור ל-Firestore והמאזין בזמן אמת כבר מוכנים. המאזין מנקה את `messagesList`, ממיר כל מסמך ל-`Message`, מוסיף אותו לרשימה ומרענן את המתאם. אין זו משימה לתלמידים.

גם ה-`ListView` וה-`ArrayAdapter<Message>` כבר מוכנים. `ArrayAdapter` מפעיל את `Message.toString()` אוטומטית ומציג את התוצאה בכל שורה של `android.R.layout.simple_list_item_1`.

## תוכנית בדיקה

1. חברו שני מכשירים, או הפעילו שני אמולטורים, עם גישה לאינטרנט.
2. התקינו את האפליקציה על שניהם והזינו שם שונה בכל מכשיר.
3. שלחו הודעה מהמכשיר הראשון ובדקו שהיא מופיעה בשני המכשירים.
4. שלחו הודעה מהמכשיר השני ובדקו שהראשון מתעדכן.
5. סגרו ופתחו מחדש את האפליקציה ובדקו שההודעות שנשמרו עדיין נטענות.

## שאלות לדיון

1. מה ההבדל בין שליחה חד-פעמית של בקשה למסד לבין מאזין בזמן אמת?
2. מדוע Firestore צריך בנאי ציבורי ללא ארגומנטים וגם getters/setters?
3. מדוע `toString()` משפיע על התצוגה במקרה של `ArrayAdapter` פשוט?
4. מה עלול לקרות אם כל הכיתה כותבת לאותו אוסף ללא כללי הרשאה?
5. איך הייתם מוסיפים לכל הודעה זמן שליחה או מזהה משתמש?

> **הערת מורה:** כל התלמידים חולקים את `board`. הודעות מבחן של קבוצה אחת נראות לכל הכיתה; תכננו את ההדגמה בהתאם.
